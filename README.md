# FitBodyStat

Aplicativo web progressivo para acompanhamento pessoal de saúde, composição
corporal, objetivos e atividades físicas.

O FitBodyStat reúne registros e indicadores em uma experiência instalável no
celular ou no computador. A plataforma também possui recursos voltados ao
acompanhamento consentido por profissionais.

## Recursos principais

- acompanhamento de peso e medidas corporais;
- indicadores de evolução e planejamento de objetivos;
- registro de atividades físicas;
- experiência PWA instalável;
- área profissional para acompanhamento autorizado;
- agenda de atendimentos;
- controles de privacidade e apresentação.

## Tecnologias

- HTML5, CSS3 e JavaScript com ES Modules;
- Firebase Authentication e Cloud Firestore;
- Service Worker e Web App Manifest.
